## ⚙️ Конфигурация (`config/`)

### `interfaces.py` — Абстрактные базовые классы

```python
BaseTool           # База для инструментов (name, get_schema, execute)
BaseLLM            # Интерфейс LLM (generate_response)
BaseLiveService    # Интерфейс Live API (start, send_audio, send_text)
BaseUI             # Интерфейс UI (start, render_frame, stop)
BaseInputHandler   # Обработка ввода (microphone_loop, keyboard_loop)
BaseOutputHandler  # Обработка вывода (broadcast, play_audio_chunk)
```

### `settings.py` — Настройки

**Внутренний агент:**
- **Модель:** `gemini-3.1-flash-lite`
- **Промпт:** Системный инструктаж агента ("сэр", краткость, уважительность)

**Голосовой фронтенд:**
- **Модель:** `gemini-3.1-flash-live-preview`
- **Промпт:** Инструкция для голосового интерфейса с делегированием
- **Инструмент делегирования:** `delegate_heavy_task` для передачи сложных задач внутреннему агенту

**Пути:** `token.json`, `credentials.json` для Google API

### `ui_config.py` — конфигурация UI

- `RENDER_INTERVAL = 33` (~30 FPS)
- `ANIM_ZONE_W = 46` (ширина зоны анимации)
- `MIN_W = 120`, `MIN_H = 30` (минимальный размер терминала для run.bat)
- `SHADING_RAMP = " .*:!?#$@"` (ASCII-символы для теней)
- `ROT_SPEED_X = 2`, `ROT_SPEED_Y = 1` (скорость вращения тора)
- `R1 = 1.0`, `R2 = 2.0` (параметры тора)

## 📋 Реализованный функционал

### 1. **Калибровка и сборка**
- `bootstrap.py` — фабричная функция для сборки приложения
- Автоматическое внедрение зависимостей между модулями
- Подключение Live API сервиса и внутреннего агента

### 2. **Ввод/Вывод (UI + Обработка команд)**

**Терминальный интерфейс:**
- ASCII-анимация (вращающийся тор) с 3D-проекцией
- Многопоточная отрисовка (~30 FPS) с параллельной обработкой ввода
- Визуальная зона чата с прокруткой истории сообщений
- Строка статуса и активный ввод пользователя
- Поддержка ввода через клавиатуру (backspace, enter, символы)

**Аудио:**
- Запись аудио с микрофона (16kHz, PCM)
- Воспроизведение аудио (24kHz, PCM)
- Очередь аудио-чанков для плавного воспроизведения

### 3. **Искусственный интеллект**

**Внутренний агент (Gemini 3.1 Flash Lite):**
- LLM для обработки естественных запросов
- Function Calling для вызова внешних инструментов
- Системный промпт с инструкциями по стилю общения ("сэр", краткость, уважительность)

**Голосовой фронтенд (Gemini 3.1 Flash Live Preview):**
- Real-time голосовой диалог
- Автоматическое распознавание речи (STT)
- Автоматический синтез речи (TTS)
- Инструмент делегирования для передачи сложных задач внутреннему агенту

### 4. **Инструменты (Tools)**

| Инструмент | Описание |
|-----------|----------|
| `TimeTool` | Текущая дата/время (русифицированные названия месяцев и дней) |
| `CalendarAddEventTool` | Создание событий в Google Calendar (обычные и all-day) |
| `CalendarAddTaskTool` | Создание To-Do задач в Google Tasks |
| `CalendarGetScheduleTool` | Просмотр расписания по календарям и задачам |

### 5. **Google Calendar Integration**
- Аутентификация через OAuth2 (автоматическое обновление токенов)
- 7 календарей: университет, учеба дома, работа, привычки, спорт, встречи, быт
- Поддержка событий и задач с фильтрацией по времени

### 6. **Конфигурация**
- `constants.py` — русифицированные месяцы и дни недели
- `settings.py` — системный промпт, модели, пути к токенам
- `ui_config.py` — настройки UI (FPS, размер зон, ASCII-шрифт)
